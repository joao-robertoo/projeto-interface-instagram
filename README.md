# 📸 Instagram Landing Page Clone

Este projeto é uma **recriação fiel (clone)** da interface visual da página de login e/ou registro do Instagram. Desenvolvido com foco no **design responsivo**, esta aplicação simula a experiência de carregamento e apresentação da tela inicial de uma plataforma web moderna.

O projeto foi construído utilizando as principais tecnologias *front-end* e serviu como um exercício prático para aprimorar habilidades em estruturação de layout, estilização e manipulação básica do DOM (Document Object Model).

## ✨ Destaques e Funcionalidades

Este clone não é apenas estático; ele incorpora funcionalidades que simulam a experiência de navegação:

  * **Experiência de Carregamento (`Preloader`):**  Antes de exibir a tela de login, o projeto exibe uma **tela de carregamento (loading screen)** estilizada. Esta funcionalidade, implementada com **JavaScript**, garante que a página só seja totalmente apresentada após o carregamento inicial, proporcionando uma transição suave e profissional ao usuário.
  * **Design Responsivo:** O layout foi minuciosamente adaptado para funcionar perfeitamente em qualquer dispositivo, desde monitores de desktop até smartphones, utilizando uma abordagem *mobile-first*.
  * **Fidelidade Visual:** Reprodução precisa dos elementos de design do Instagram (cores, fontes, ícones e alinhamentos).
  * **Interatividade com JavaScript:** O uso de JavaScript permitiu adicionar uma camada de dinamismo, essencialmente para a gestão da tela de carregamento e futuras interações.

📱 Responsividade e Layout
A responsividade foi o pilar central deste projeto. Garantiu-se que a experiência de uso seja impecável, independentemente do tamanho da tela.

Abordagem Mobile-First: O desenvolvimento começou priorizando a estrutura e a estilização para telas menores (smartphones), e subsequentemente, aprimorado para telas maiores.

Técnicas de CSS3: Utilização avançada de Flexbox para o alinhamento centralizado do cartão de login e distribuição horizontal e vertical dos elementos.

Media Queries: Aplicação de @media queries estratégicas para reestruturar o layout em pontos de interrupção chave, como:

Remoção ou redimensionamento do painel lateral de imagens em desktop para telas menores.

Ajuste das dimensões e espaçamentos do formulário para caber confortavelmente em dispositivos móveis.

## 🛠 Como Executar Localmente

Para clonar e rodar o projeto em sua máquina:

**1. Clone o repositório:**

```bash
git clone https://github.com/joao-robertoo/projeto-pagina-instagram.git
```

**2. Navegue até o diretório:**

```bash
cd projeto-pagina-instagram
```

**3. Abra o `index.html`:**
Simplesmente abra o arquivo `index.html` em seu navegador para iniciar o projeto.
